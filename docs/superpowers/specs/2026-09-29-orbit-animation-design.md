# 伴星がアイコンを周回するアニメーション SVG の設計

- 日付: 2026-09-29
- 状態: 設計確定・未実装
- 関連: PR #345（アプリアイコンの刷新）、試作と比較ページ https://claude.ai/artifact/QY2mD6duDxtY8Dca4x8PPt

## 0. 目的

PR #345 で決めたアプリアイコン（菱形の結晶＋レンズ）の周りを、小さな伴星が回るアニメーション画像を作る。アプリ名の由来であるスピカ（乙女座 α 星）が近接連星であることを表す。置き場所は 2 つある。

| 置き場所 | 表示 | 背景 |
|---|---|---|
| GitHub の README 冒頭 | 中央揃え、200px | GitHub のライト（`#ffffff`）/ ダーク（`#0d1117`）テーマ |
| About ダイアログ（F1） | 112px（今の静止ロゴ 60px から拡大） | `#1a1a1a` 固定 |

表示している間は、伴星がずっと回り続ける。

## 1. 画像形式

**アニメーション SVG（SVG 内の CSS keyframes）を採用する。** README でも About ダイアログ（WebView2）でも `<img>` で読み込む。`<img>` 内の SVG ではスクリプトは動かないが、CSS アニメーションは動く。

| 形式 | 判断 | 理由 |
|---|---|---|
| アニメーション SVG | 採用 | ベクターなのでどの大きさ・DPI でもくっきり表示される。透明部分がなめらかで、ライト / ダークどちらの背景にもなじむ。数 KB で済む。SVG 内の `prefers-reduced-motion` で「アニメーションを減らす」設定に従える。1 ファイルを両方の置き場所で使える |
| APNG / animated WebP | 不採用 | 解像度が固定で、高 DPI 用に 2 倍の大きさで作る必要がある。100〜300KB 程度になる。アニメーションを減らす設定に従えない。コマの書き出しと組み立てを行う仕組みが別に要る |
| GIF | 不採用 | 透明部分が「完全に透明か不透明か」の 2 択しかなく、ダークテーマで縁がギザギザになる。256 色では影の半透明がきれいに出ない |
| 動画（MP4 など） | 不採用 | GitHub では透明を扱えず、README での自動ループ再生にも向かない |

## 2. 見た目と動き（確定値）

座標はすべて 1024×1024 のキャンバス上の値。比較ページでの確認を経て、ユーザーが確定した。

| 項目 | 値 |
|---|---|
| 主星 | `public/icon.svg` を 80% に縮め、中心を (512, 492) に置く |
| 軌道 | 楕円。中心 (544, 573)、横半径 500、縦半径 143、-18° 傾ける。中心は主星より 32 右に置く（中央に置くと左に寄って見えたため） |
| 手前の軌道 | `#6CC4FF`、太さ 51、輪郭なし |
| 奥の軌道 | `#0F4C9E`（不透明）、太さ 51 |
| 伴星 | 青い丸 `#1667D6`（半径 68）に、白い縁 9（外側の半径 77） |
| 周期 | 4.01 秒（スピカの公転周期 4.01 日にちなむ）。一定の速さで回る |
| 回り始め | 軌道上の角度 150°（手前の左下）。止まって表示されるときもこの配置になる |
| 全体の配置 | すべての要素（軌道の端に来た伴星も含む）が、キャンバスの内側 16 に収まるよう全体を縮小し、中央に置く |

軌道上の角度 θ は、傾ける前の楕円での角度とする。θ = 0° が右端、θ = 0°〜180° が手前（画面の下側）の半周にあたる。θ は時間とともに増える。つまり伴星は、手前では右から左へ、奥では左から右へ進む。

奥の軌道を不透明にしたのは、半透明だと白い背景で手前の軌道より明るく見えたため（O6）。

## 3. 描画の仕組み

試作で見つかった不具合を、次の不変条件で防ぐ。実装のコメントからは `(O1)` の形で参照する。

- **O1 楕円上の移動:** 伴星は、円を縦に K = 143 / 500 倍して潰した座標系の中で `rotate()` し、楕円を描かせる。変換の並びは `spin(θ) · translate(500, 0) · counter(−θ) · scale(1, 1/K)` とする。こうすると、回転と潰しが打ち消し合い、伴星自体は常に真円のままになる。`spin` と `counter` は同じ周期で逆向きに回す CSS アニメーションにする。CSS の `offset-path` や SMIL は使わない。SMIL は CSS の `prefers-reduced-motion` で止められないため。
- **O2 前後の入れ替え:** 伴星は 2 つ描く。1 つは主星の下（奥用）、もう 1 つは最前面（手前用）。手前用は θ が 0°〜180° の間だけ表示し、θ = 0° と 180° で opacity を `step-end` で一瞬で切り替える。伴星を半面ずつ切り抜く方法は使わない。右端で伴星が主星の角と重なる間、縁が主星に食い込んで見えたため。
- **O3 入れ替わる瞬間の隙間:** θ = 0° と 180° で、伴星の円（半径 77）が主星の菱形と重ならないこと。重なると、入れ替わりが一瞬の「ちらつき」として見える。軌道の横半径 500 はこのために広げた値。隙間は θ = 0° で約 67、180° で約 137 になる。
- **O4 手前の軌道は 2 回描く:** 1 回目は軌道の手前半分全体を、両方の伴星より下に描く。こうすると、奥を通る伴星の上に軌道の切れ端が乗らない。2 回目は、主星に重なる部分だけを主星より上に描く。こうすると、軌道が主星の前を横切って見える。2 回目の切り抜きには主星を 1% 大きくした菱形を使う。主星の縁のぼかし（アンチエイリアス）が、軌道に細い線として残らないようにするため。
- **O5 止まっているときの絵:** 回転の初期値（アニメーションがないときの `transform`）を回り始めの角度 150° にする。こうすると、`prefers-reduced-motion: reduce` のときや、アニメーションを再生しない環境でも、整った 1 枚の絵になる。
- **O6 奥の軌道の色:** 奥の軌道は不透明にする。半透明にすると背景色が透け、白い背景では手前の軌道より明るく見えてしまう。
- **O7 GitHub で表示できる要素だけを使う:** スクリプト、外部フォント、外部ファイルの参照、`foreignObject` は使わない。使うのは図形、`<style>`、`clipPath` だけとする。

## 4. ファイル構成と生成

| ファイル | 内容 |
|---|---|
| `scripts/build-orbit-svg.mjs`（新規） | `public/icon.svg` を読み込み、§2・§3 に従って `public/spica-orbit.svg` を書き出す。数値の計算（全体の縮小率、O3 の隙間）もここで行う |
| `public/spica-orbit.svg`（新規・生成物） | リポジトリにコミットする。README と About ダイアログの両方が参照する |
| `scripts/__tests__/build-orbit-svg.test.mjs`（新規） | `node:test` で書く（`build-file-icon.test.mjs` に倣う） |
| `package.json` | `build:orbit` と `build:orbit:test` を追加する |

生成したファイルをコミットする運用は `build:file-icon` と同じ。アイコンを直したら `npm run build:orbit` を 1 回実行すれば、アニメーションにも反映される。

試作では全体の縮小率を、白い縁 18 の伴星（外側の半径 86）で計算していた。生成スクリプトは実際の外側の半径 77 で計算するので、縮小率は 0.880 から 0.894 になる。全体が約 1.6% 大きくなり、余白はちょうど 16 になる。

テストで確かめること:

1. 生成結果が、コミットした `public/spica-orbit.svg` と一致する（アイコンだけ直して、生成し忘れるのを防ぐ）
2. θ = 0° と 180° で、伴星と主星の間に隙間がある（O3）
3. すべての θ で、伴星がキャンバスの内側 16 に収まる（§2 の配置）
4. SVG にスクリプト・外部ファイルの参照・`foreignObject` が含まれない（O7）

スクリプトのテストは今の CI では実行されていない（`build:file-icon:test` も同じ）。CI に加えるかどうかは、この設計の範囲外とする。

## 5. 組み込み

- **README:** 冒頭の見出し `# Spica Photo Viewer` の上に、中央揃えで追加する。見出しと本文は変えない。
  ```html
  <p align="center"><img src="public/spica-orbit.svg" width="200" height="200" alt="Spica Photo Viewer logo"></p>
  ```
- **About ダイアログ（`src/components/AboutDialog.tsx`）:** ロゴを `/icon.svg`（60px）から `/spica-orbit.svg`（112px）に替える。ダイアログが閉じている間はコンポーネントが何も描かないので、アニメーションは開いている間しか動かない。
- **`src/App.css` の `.logo-icon`:** アイコン文字だった頃の `font-size: 48px` が残っていて、画像の下に余計な行の高さを作る。画像のレイアウトに合わせて整える。
- **変えないもの:** ファビコン、ウインドウのアイコン、関連付けアイコンは今までどおり静止画を使う。

## 6. 検証計画

自動:

- `npm run build:orbit:test`（§4 のテスト）
- `AboutDialog.test.tsx` に、ロゴが `/spica-orbit.svg` を指すことの確認を 1 件追加
- `npm test`、`npm run type-check`、lint / format
- e2e の画像比較テストは About ダイアログを撮影していないので、基準画像の更新は要らない

目視:

1. `npm run tauri dev` で F1 を押し、About ダイアログでアニメーションが動くことを確かめる
2. Windows の「アニメーション効果」をオフにし、止まって表示されることを確かめる（O5）
3. ブランチを push し、GitHub のブランチページで README を表示して、ライトとダークの両テーマで見た目と動きを確かめる

## 7. 実装フェーズ

1. 生成スクリプトとテスト（§4）。試作（セッションの一時フォルダにある `orbit.mjs`）を元に、§3 の不変条件をコメントで参照できる形に整える
2. `public/spica-orbit.svg` を生成してコミット
3. About ダイアログと CSS（§5）、`AboutDialog.test.tsx`
4. README（§5）
5. 検証（§6）

## 8. リスク

- **GitHub がアニメーションを再生しない場合がある:** GitHub モバイルアプリなどでの挙動は未確認。再生されなくても O5 により止まった絵として崩れないので、許容する。
- **README 画像のキャッシュ:** GitHub は README の画像をキャッシュするため、再生成後すぐには反映されないことがある。
- **CSS transform の解釈の違い:** O1 は、SVG 要素への CSS `transform` が要素の座標系の原点を基準に回ることを前提にしている。CSS の既定値（`transform-box: view-box`、`transform-origin: 0 0`）はこの前提どおりで、試作は Edge・Chrome・Firefox で正しく動いた。Safari では確かめていない。ブラウザによる違いを避けるため、この 2 つを SVG 内で明示する。
